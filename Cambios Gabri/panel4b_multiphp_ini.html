MultiPHP INI Editor

Panel 3 — Paso 2
El MultiPHP INI Editor permite ajustar la configuracion PHP (php.ini) por dominio. Selecciona el dominio y modifica los valores según las necesidades de cada instalacion WordPress.

Editor de configuracion PHP.INI

Configura los parametros PHP especificos para el dominio seleccionado.

Dominio:
Limites de recursos
memory_limit MB
Maxima memoria que puede usar un script PHP.
max_execution_time seg
Tiempo maximo de ejecucion de un script.
max_input_time seg
Tiempo maximo para procesar datos de entrada.
max_input_vars vars
Numero maximo de variables de entrada.
Subida de archivos
upload_max_filesize MB
Tamano maximo de archivos subidos.
post_max_size MB
Tamano maximo de datos POST enviados.
file_uploads on/off
Permitir subida de archivos via HTTP.
Habilitado
max_file_uploads archivos
Maximos archivos subidos por peticion.
Gestion de errores
display_errors produccion
Mostrar errores en pantalla (desactivar en produccion).
Desactivado
log_errors recomendado
Registrar errores en el log de PHP.
Habilitado
error_log ruta
Ruta del archivo de log de errores PHP.
Sesiones
session.gc_maxlifetime seg
Duracion maxima de una sesion de usuario.
session.cookie_secure SSL
Enviar cookies de sesion solo por HTTPS.
Habilitado
session.use_strict_mode seguridad
Rechazar IDs de sesion no inicializados.
Habilitado
